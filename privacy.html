Privacy Policy

Agent Ngegas · Last updated 12 November 2026

Data we receive from TikTok

When the ngegas.tech team connects its TikTok account, Agent Ngegas receives:

  • Basic profile information: open ID, display name and avatar (scope user.info.basic).
  • An access token and refresh token that allow posting videos to that account (scope video.publish).
  • The account's available privacy options, read just before each post.

How we use it

We use this data only to post videos the team has approved to the team's own TikTok account and to confirm each post succeeded. We do not use it for advertising, profiling or any other purpose.

Storage and security

Tokens are stored on the team's own server in a file readable only by the service. They are never shared, sold or sent to any third party. Videos and captions are created by the team and are sent only to TikTok.

Other people's data

Agent Ngegas does not collect data about viewers or other TikTok users.

Retention and deletion

Tokens are kept until access is revoked. Removing Agent Ngegas in the TikTok app (Settings, Security, Manage app permissions) invalidates them, and we delete the stored copy. You can also ask us to delete it.

Contact

Send a direct message to @ngegas.tech on TikTok.
